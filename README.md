# Hoshy Peng

Personal homepage: https://hoshy667.github.io

Uses [Hydejack 9.2.1](https://github.com/hydecorp/hydejack/tree/v9.2.1) with its original cover background and typography. The homepage displays only the GitHub avatar and display name from [Hoshy667](https://github.com/Hoshy667), retrieved on 2026-10-25.

The avatar is saved locally as `avatar.jpg`. Personal content is configured in `_config.yml`; the cover adjustments are in `index.html`. No biography, projects, contact details, or sample posts are included.

## GitHub Pages

Publish the `main` branch from `/ (root)` using the GitHub Pages branch build. The `jekyll-remote-theme` plugin downloads the pinned original theme and its assets during the build.

For a local preview with a supported Ruby and Bundler installation:

```sh
bundle install
bundle exec jekyll serve
```
